# 3X-UI (定制汉化 & 稳定加固版)

本项目是专为中文用户打造的高性能、全本地化 Xray 可视化管理面板。完全剥离外部无关依赖与外链，专注生产环境下的极致稳定性与操作体验。

**核心版本规范：**
- **面板版本固定：** `3.4.2`（锁定稳定版本，关闭对外自动检测与误升级）
- **Xray 核心版本固定：** `v26.6.27`（锁定经验证最为稳定、兼容性最佳的核心，规避新版本协议变更及偶发 BUG）

---

## 🌟 主要改动与优化特性

### 1. 深度中文汉化与本地化 (100% Chinese Localization)
- **全面操作提示汉化**：无论是首次运行 `install.sh`、通过 `update.sh` 维护，还是在终端运行 `x-ui` 管理脚本，全部 300+ 处交互提示、日志输出、菜单项、状态报告均已完全汉化，表达规范清晰。
- **Go 后端与 CLI 汉化**：全面汉化 `main.go` 命令行参数帮助（`-help` / `-v` / `-reset` 等）、运行时控制台日志（数据库迁移、端口变更、服务启动、两步验证重置等）。
- **默认环境适配**：默认界面语言与 Telegram 通知模板语言锁定为 `zh-CN`，容器与系统默认时区优化为 `Asia/Shanghai`。

### 2. 独立纯净与版本锁定 (Decoupled & Version Locked)
- **摒弃原版外部依赖**：彻底剥离上游项目外链、赞助入口（Donate）及外部 Telegram 群组跳转，打造纯净自托管体验。
- **面板版本固化**：面板版本固定为 `3.4.2`，后台版本检测 API 锁定为当前稳定版本，避免频繁提示升级或误触破坏现有环境。
- **Xray-core 核心锁定**：下载源及核心版本切换列表中封顶并默认采用 `v26.6.27`，彻底避免升级高版本引入的连接崩溃或配置解析兼容性问题。

### 3. SSL 证书申请流程极致优化 (SSL Issuance Hardening)
- **下载源自动容灾（`ghproxy`）**：在 `acme.sh` 官方安装源连接超时或受阻时，自动无缝切换至国内加速镜像源，确保 100% 成功部署 acme 客户端。
- **DNS 解析预校验**：在调用 acme.sh 申请证书前，脚本会自动比对域名公网解析 IP 是否与当前服务器 IP 一致，有效避免因配置错误频繁申请导致被 CA 封锁。
- **端口冲突 & 占用自动处理**：验证端口（80/自定义端口）如果被 Nginx、Caddy、Apache2 等服务占用，脚本将临时停止这些服务，并在验证完成后自动恢复。
- **防火墙端口智能放行**：申请时临时在 UFW、Firewalld 或 iptables 防火墙中开放验证端口，申请完毕后自动闭合。
- **100% 恢复保障（Trap 机制）**：引入系统信号捕获（Trap），**无论证书申请成功、失败还是中途按 Ctrl+C 中断，脚本都能保证将防火墙规则和被占用的 Web 服务完璧归赵**，绝不破坏现有服务器业务。
- **ZeroSSL 备用 CA 灾备**：若 Let's Encrypt 遇到申请限制或服务器宕机，脚本会自动 fallback 切换到 ZeroSSL 并绑定账户，提供双重保险。
- **IPv6 双栈智能感知**：仅在服务器拥有 IPv6 且域名解析有 AAAA 记录时才启用 `--listen-v6` 监听，防止单栈环境下报错。

## 🚀 快速开始 (Quick Start)

### 一键安装 (Install)
在您的服务器终端运行以下命令进行全新汉化版安装：
```bash
bash <(curl -Ls https://raw.githubusercontent.com/lgdglgc/3x-ui/main/install.sh)
```

### 一键更新 (Update)
若要更新已安装的面板，同时保留现有配置和数据：
```bash
bash <(curl -Ls https://raw.githubusercontent.com/lgdglgc/3x-ui/main/update.sh)
```

### 命令行管理面板
安装完成后，在终端直接输入 `x-ui` 即可呼出全中文管理菜单：
```bash
x-ui
```
